# Fudan VPN Windows（非官方预览版）

基于 [wyleeyuan/fudan-vpn](https://github.com/wyleeyuan/fudan-vpn) 的 Windows 移植，
使用用户态网络栈连接校园 aTrust，并提供本地 SOCKS 接口及系统托盘。
本目录是独立整理的源码，当前不自动发布到 GitHub。
来源、基础提交和许可见 [NOTICE.md](NOTICE.md) 与 [LICENSE](LICENSE)。

支持范围为 Windows amd64 预览版，需要 Microsoft Edge WebView2 Runtime。
不提供 macOS/Linux 安装包，不要求管理员权限，不创建系统服务、开机自启或第二个 TUN。
请仅访问你有权使用的服务，并遵守学校网络使用要求。

## 日常使用

1. 从本源码构建，完整解压 Windows 包到固定目录，保留两个 EXE、rules.conf 和随附文档。
2. 双击 `fudan-vpn.exe`。先填写你要访问的**一个 IPv4 地址**，点击“保存设置”。
   默认目标为空，不会自行连接任何实验室地址。
3. 默认使用正常 TLS 验证。若指定校园数据隧道的证书异常，会连接失败；
   仅在理解 [TLS 风险](SECURITY.md) 后，才能自行启用兼容选项。
4. 点击“连接”或“打开登录页”，在本机 WebView2 认证窗口完成扫码/密码/二次认证。
   无需复制回调，切勿把凭据或完整回调发到 issue。
5. 托盘显示未连接、连接中、已连接或故障。关闭主窗口会隐藏到托盘；
   用菜单“打开主界面”“重新连接”“断开”“查看日志”“退出”管理。
   “退出”只停止经路径、PID、创建时间确认归属的受管理引擎。

Windows 登录使用 CDP Fetch 在 Request 阶段暂停并中止 OAuth 回调，避免浏览器提前消费一次性 code。
回调通过私有登录子进程管道传回桌面，再通过引擎环境传递；桌面不把授权码写入进程命令行或日志。
使用系统账号权限仍能读取进程内存/环境，本程序不是凭据隔离沙箱。

公开版配置在 `%APPDATA%\FudanVPNWindows`，与既有客户端目录分离。
`settings.json` 仅保存目标与 TLS 开关；`client_data.json` 是敏感会话缓存，不可分享。
设置只能在断开且无认证窗口时修改。保存后再连接，不能热改运行中的目标。
重复启动会显示同一公开版窗口，不另起引擎；端口被其他安装占用时会拒绝连接，不能同时运行两套引擎。
同目录引擎的接管仍需状态证据与设置匹配；不会按进程名批量终止程序。

## 状态证据的边界

“已连接”要求：受管理进程身份一致，1082 监听属于该进程，状态快照新鲜且对应本次运行，
用户态/无 upstream/单目标 /32 策略有效且与已保存设置一致，认证会话有效，
至少一个已认证 L3 隧道最近仍收到服务器帧。仅进程或端口存在不会显示已连接。
心跳状态不保证目标 SSH 服务可用，不持续探测实验室服务器。
引擎退出、状态过期、隧道故障或重连会降级托盘状态。

## Clash 配合使用（手动、单目标）

本客户端不修改 Clash、系统代理、全局 DNS 或系统默认路由。
在你自己的 Clash 扩展中添加 [示例节点与规则](examples/clash-campus.example.yaml)，
把示例的 `192.0.2.10` 替换为与客户端设置相同的目标。
这是文档保留地址，不能用来做真实连通性测试。
只交给校园节点该 /32 的 TCP；目标 UDP 拒绝；引擎进程先直连，规则放在通用私网规则之前。
节点指向 `127.0.0.1:1082` 且 UDP 关闭。

Clash 可独立开启 TUN 并保持规则模式；检查进程识别有效，勿让引擎到校园网关的连接再次回到自身 SOCKS。
不要将目标 /32 加入 TUN 路由排除，否则目标会绕过 Clash。
使用前备份自己的配置，本项目不分发个人订阅、API secret、DNS 或全局路由设置。
按你的 Clash 版本将示例合并到持久扩展中；不要直接覆盖完整订阅。

1082 的 `-router-strict-cidr <目标>/32` 优先强制该 IP 通过 VPN，隧道失败时返回失败，
即使普通直连可达也不会回落。其余请求仍按 rules.conf 分流；
默认规则还包含上游校园域名及学术资源，不应把整个系统流量交给这个端口。
1080 是裸 VPN SOCKS，1081 是 HTTP 代理，均只绑定回环。
`-no-upstream` 保持启用；引擎不用第二个 TUN。

确认 SOCKS 实际走隧道后，再运行 `ssh <你的用户名>@<目标IPv4>`，
无需 ProxyCommand。验证时区分 TCP 端口、SSH 握手和认证登录，并用 Clash 节点命中记录与引擎 VPN 转发日志交叉核对。
官方 VPN 路由可能造成假成功：应先记录恢复方法，再做可恢复的隔离及隧道故障负向验证。

## 构建与检查

安装 desktop/go.mod 指定的 Go 版本（当前 1.27.3），在本目录使用 PowerShell：

```powershell
.\scripts\Build-Windows.ps1
# 或指定已安装的工具链：
.\scripts\Build-Windows.ps1 -GoExe 'D:\Tools\Go\bin\go.exe'
```

脚本对两个模块下载/校验依赖、执行完整测试、编译正式 EXE，生成
`build\FudanVPN-Windows-<版本>-amd64.zip` 和 SHA256SUMS。
构建使用 CGO_ENABLED=0、trimpath、桌面 production 标签及 windowsgui；
依赖保留 go.sum 校验，没有关闭 GOSUMDB。
可按常规 Go 方式自行设置 GOMODCACHE/GOCACHE，不需要把缓存加入仓库。
不依赖 Node、npm、Wails CLI、上游 macOS 资源或本机私有路径。
发行引擎只允许 `-protocol atrust`；保留的 EasyConnect 源码不对本发行 CLI 开放。

Windows CI 使用同一脚本并上传 Actions 构建产物；没有自动创建 Release 或推送仓库的步骤。
发布者应将**对应这次构建的完整源码归档**与二进制一起提供；
不要仅分发 EXE。审阅说明见 [docs/testing.md](docs/testing.md)。

## TLS 兼容选项

默认关闭，桌面勾选保存后才传入 `-fudan-tunnel-tls-compat`。
例外仅匹配 TCP 数据隧道的字面端点 `175.186.248.37:441`；
该端点的数据隧道及节点 TLS 延迟探测将接受过期、自签名、身份不匹配的证书，存在中间人攻击风险。
此举不是取得可信证书，也不是修复服务端证书。
其他 IP、其他端口、域名别名、登录网站、OAuth HTTPS 和其他 HTTPS 继续正常验证。
如果学校更换节点，例外不会自动扩大，请联系学校修正证书或使用能正常验证的节点。

## 日志、排错与卸载

托盘“查看日志”打开主界面的运行日志；持久日志为配置目录中的 `desktop.log`。
分享前自行检查并脱敏，默认日志也可能含目标地址、节点、路径、时间等元数据。
不要开启 TLS key log、PCAP/debug 后上传抓包；禁止提交会话缓存、回调、密码或私钥。
连接失败先看状态原因及 [安全说明](SECURITY.md)，不要反复扫码掩盖隧道错误。

退出后可删除分发目录；清理会话时另行删除公开版配置目录。
恢复使用原客户端只需保持公开版退出，再按原方式启动；本版不会迁移或覆盖原配置。
本程序未做 Authenticode 签名。不要盲目绕过来源警告；从你信任的源码构建并核对摘要。
